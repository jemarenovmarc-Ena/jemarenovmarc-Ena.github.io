JEMA RENOV — SITE MIS À JOUR AVEC VOS PHOTOS

IMPORTANT : ne téléversez pas le fichier ZIP lui-même sur GitHub.
1. Téléchargez puis décompressez ce ZIP sur votre ordinateur.
2. Ouvrez votre dépôt GitHub : https://github.com/jemarenovmarc-Ena/jemarenovmarc-Ena.github.io
3. Cliquez sur Add file > Upload files.
4. Sélectionnez les fichiers du dossier décompressé : index.html, styles.css, script.js, mentions-legales.html, robots.txt, sitemap.xml et le dossier assets.
5. Si GitHub vous demande de remplacer les fichiers existants, confirmez. Le dossier assets contient le logo et les photos.
6. En bas de page, cliquez sur Commit changes.
7. Attendez une ou deux minutes puis ouvrez https://jemarenovmarc-ena.github.io/

Ne supprimez pas le dossier assets : il contient les images utilisées par le site.
Avant publication, vérifiez que vous avez l’autorisation d’utiliser les photos des logements.
Complétez également les champs encore manquants dans mentions-legales.html.
